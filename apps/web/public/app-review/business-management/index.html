Step 1: Open App Review demo

App Review demo — business_management

OmniMsg discovers Business Manager assets so WhatsApp onboarding can attach the correct WABA. This demo runs the same Graph calls the backend uses in production.

  • Admin opens OmniMsg App Review demo
  • Admin starts Business Manager asset discovery
  • Backend calls Meta Graph with System User omnimsg_api
  • OmniMsg shows businesses and owned WABAs

Production use of business_management is server-to-server via System User omnimsg_api. There is no end-user Facebook Login or permission grant screen for this permission.

Results — Business Manager discovery

Click Discover Business Assets. OmniMsg will call Meta Graph from the backend (System User) and show GET /me/businesses (informative), GET /{business-id}, and GET /{business-id}/owned_whatsapp_business_accounts.
